A for...og loop is used when you need to loop over values from an iterable. Examples of iterables would be arrays, and strings.

for (varuable of iterable){
  //code block executed
}

The variable in the example represents the current value of the iterable that is being lopped over.

In this first example we have an array of numbers and we want to loop over eaxh number and log it to the console.

const numbers = [1,2,3,4,5];
for (const num of numbers){
  console.log(num);
}

We have created a variable called num that will represent the current number in the array. for the iteration 1, num will be 1 for iteration2, num will be 2 , and so on.

Another Example where we have a string and we want to loop over each chracter and log it to the console.

const str = 'freeCodeCamp';

for (let char of str){
  console.log(char);
}

in this example, we have created a variable called [char] that will represent the current in the string.

const people = [
  {name:'Jhon', age:30}

  {name:'Jim', age:40}
];

for(const person of people){
  console.log(`${person.name} is ${person.age} years old`);

In this example, we have an array of objects called people. Each object has a name and age property.

for..of loops are really useful when you need to loop over values from an iterable like an array or a string. They are also easy to read and can make your code more concise.
